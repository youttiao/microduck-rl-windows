## 二、⭐ 跟"Windows 上训练"直接相关的

### `CdyDoodle/maxy_duck` — Windows 原生的完整方案
> The duck on a Windows PC: simulation running natively with the same BAM servo model and the official policies, training in WSL on the official stack, and a web monitor with live learning curves. Apache-2.0, in English and Chinese.

**Windows 原生跑仿真 + WSL 里训练 + Web 界面看曲线**，中英双语。走的是"WSL 训练"路线，和本仓库的"Windows 原生训练"路线互补 —— 如果你的 WDDM/CUDA graph 出问题，这是现成的退路。

### `Qi-hub-dot/microduck-locomotion-diagnosis` — 中文，且专门讲了 Windows
> Reproduces upstream issue #46, where the walking task converges to standing still, and traces it to three reward and metric flaws. **Also notes how to run the CUDA-only stack on Windows.** In Chinese.

两个价值：
1. **复现了上游 issue #46**：走路任务收敛成"站着不动"，根因是三个奖励/指标缺陷。修法：把奖励门控在"确实产生了位移"上 + 重新加权横向误差，`error_vel_xy` 从 0.43 降到 0.21。**如果朋友训出来只会站着，先看这个。**
2. 有中文的 Windows 上手说明。

### `xinhuagu/my-microduck-journal` — WSL2 路线，每个死胡同都记了
> Retraining the skills from scratch on one consumer GPU under WSL2, with every number and dead end logged. It shows the walk-and-get-up skill can't be trained from the public recipe without private teacher checkpoints, and rebuilds those teachers locally.

诚实的一篇。**重要发现：walk-and-get-up 技能用公开配方训不出来，因为缺私有的 teacher checkpoints**，作者自己在本地重建了 teacher。

### `OneRobotAI/microduck` — 一键脚本，中文
> Two scripts that take a bare Linux box from no environment to a usable gait and an exported ONNX with its validation, timed at about four hours on an RTX 5060 Ti. In Chinese.

### `microduck-rl-on-thor` — aarch64 CUDA 硬件
> Getting the official training stack to run on aarch64 CUDA hardware (Thor, DGX Spark, Jetson), with every trap documented and verified on real machines. **In English and Chinese.**

虽然目标是 ARM，但里面"CUDA 硬件上每一个坑"的部分和本仓库发现的 Windows torch 问题属于同一类，值得一读。

### `witcheer` 一家最系统
把官方整套策略用 **±1° 齿隙**重训了一遍，每个都是 `walk` 槽位的候选：平地 / 崎岖 / 斜坡 / 单级台阶 / 短楼梯 / 滑地面 / 逆风 / 走路+自恢复，外加起身、前滚翻、右脚踢、300mm 大球踢。**每张卡片都记了训练和仿真的踩坑，包括没成的。** 刷踢球的球必须放在脚尖（策略对球是盲的）。

### `mindthink/microduck-policies-repro` — 复现官方的，还修了 bug
独立复现官方 walk 和 `velstand` 配方，**并带了一个修复 `velstand` 在低速指令下站着不动的补丁**。如果你训出来的 `velstand` 不跟速度指令走，看这个。

### 硬核实验
- `HannesVonEssen/microduck-backflip` / `microduck-long-jump` — 0.8m 高的后空翻、30cm 远跳。**卡片明确警告落地可能摔坏机器人**
- `chenp9527/microduck-jump` — 原地跳 3-6cm。**诚实地记着自己的验收清单没过**：128 次落地里一半在目标带内，落地峰值 128N vs 目标 40N
- `llama/microduck-beak-throw` — 用嘴甩出 24mm 球再站稳。50/50 通过率**但前提是加了运行时钳位**，严格的无钳位检查是不通过的
- `zachgarner/microduck-headstand` — 六个策略串成一套杂技：折叠、踢起、滚回、劈叉倒立、劈叉站起。**96 次里 87 次完整成功**
- `ros-claw/microduck` — **三只鸭子一起跳长绳**，两只转绳一只跳

## 七、值得注意的两个"坑"

1. **上游 issue #46：走路任务收敛成站着不动。** 根因是三个奖励/指标缺陷。修法见 `Qi-hub-dot/microduck-locomotion-diagnosis`。**训练时如果 mean reward 在涨但机器人不动，先查这个。**
2. **社区策略大多是 "Sim-only"。** awesome 列表用 `*Sim-only.*` 标注，指的是**没有在真机上验证过**。少数几个（happy-hop、footsteps、static-grasp）明确说过跑在实体机器人上。装任何社区策略前，**第一次务必把鸭子放在支架上**。
